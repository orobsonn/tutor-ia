# Glossário

| Termo | Significado |
|---|---|
| POC | Demonstração do comportamento proposto com dados fictícios |
| MVP | Primeiro recorte operável com pessoas reais, a ser delimitado depois |
| Tentativa | Uma realização ou agendamento específico de prova; nova realização não apaga a anterior |
| Realização | Se o aluno efetivamente fez a prova |
| Resultado | Aprovado, reprovado ou pendente; inicialmente declarado pelo aluno |
| Aderência do curso | Percepção da correspondência do conteúdo estudado com o encontrado na prova |
| Aderência dos simulados | Percepção da correspondência de conteúdo, formato e dificuldade com a prova |
| Desempenho no simulado | Respostas/acertos por questão ou notas; não é coletado nesta POC |
| D+X | Contato X dias depois da data de prova; intervalo ainda configurável |

Não confundir aderência com cumprimento de plano. Não inferir qualidade apenas por aprovação/reprovação. Quem não usou um recurso não é um avaliador negativo desse recurso.
