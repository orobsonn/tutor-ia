# ADR-002 — Dados fictícios e independência acadêmica

- Status: aceita para o recorte atual.
- Data: 24/10/2026.
- Origem: alinhamento de produto e instrução do responsável do projeto, sintetizados sem identidades privadas.

## Contexto

O ciclo de feedback pode ser demonstrado com informações fornecidas pelo participante.

## Decisão

Usar dados fictícios e tempo simulado; não integrar API acadêmica na POC.

## Alternativas consideradas

Conectar primeiro a plataforma real adicionaria dependências sem necessidade para demonstrar o ciclo.

## Consequências

A POC valida experiência e utilidade percebida; não homologa integração ou operação com pessoas reais.

## Em aberto

Canal de demonstração e stack não foram escolhidos.
